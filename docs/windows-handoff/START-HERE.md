# Start here — Windows / Claude Code

1. Extract this ZIP to a local development directory, e.g. `C:\Projects\Quintech-Claude-Handoff`.
2. Open that directory in Claude Code (or open PowerShell there and run `claude` if installed). The root CLAUDE.md contains the project instructions. If using a regular Claude chat instead, attach CLAUDE.md and the source files; chat alone cannot build on your PC.
3. Paste the following prompt:

> Read CLAUDE.md and inspect the included v1.0.0 source. I am running Windows and Bitfocus Companion 5.1.0. Continue this project locally, verify the correct Companion API, build and test the module, and produce a ready-to-extract Developer Mode ZIP with runtime dependencies included. Preserve the existing Quintech commands and module identity. Do not modify the GitHub repository or live hardware without my approval. Start by checking my local environment and report any blockers.

The original source and compiled files are included, but node_modules and a lockfile are not. This handoff is not itself a verified Windows runtime package. The reference PDF is included unchanged. No historical screenshots or logs are included because they are not required for the initial build and may contain machine-specific information.
